      Options de révision

      Écris la phrase dans la question et entoure chaque mot à trouver de doubles accolades : {{overtourism}}. Indice facultatif après deux deux-points : {{overtourism::surtourisme}}. Plusieurs réponses possibles : {{crowded/packed}}. La réponse peut contenir une traduction ou une explication.

      Utilisée pour la saisie, les QCM et les associations. Plusieurs réponses acceptées : sépare-les par « / ». Majuscules, accents et articles (to, a, the, le…) sont tolérés.

      Ces options s'appliquent au sens question → réponse. La carte inversée se révise toujours en mode classique ; un texte à trous n'a pas de carte inversée.

            Révision

            Rythme quotidien

            Nouvelles cartes à découvrir et révisions maximum chaque jour (0 révision = sans limite). « Du jour » : la matière est mélangée aux autres dans la Révision du jour ; sinon, elle se révise seulement avec son propre bouton.

            Planification

            Probabilité de te souvenir d'une carte au moment où elle revient. Plus elle est haute, plus les intervalles sont courts.

            Une nouvelle carte revient après chacune de ces étapes avant de passer à plusieurs jours.

            Programme TSI

            Coche les chapitres à inclure dans la révision du jour. Les chapitres décochés restent disponibles en bachotage et dans l'éditeur.

            Notifications

            Rappels envoyés environ une fois par heure par GitHub, avec 15 à 40 minutes de décalage après l'heure choisie. Les réglages valent pour tous tes appareils.

            Cet appareil

            1. Ouvre ce site dans Safari.
            2. Touche Partager, puis Sur l'écran d'accueil.
            3. Ouvre l'appli Flashcards depuis l'écran d'accueil, puis reviens ici. Il faudra y recoller ton jeton GitHub une fois : l'appli de l'écran d'accueil ne partage pas les réglages de Safari.

            Compte et données

            Synchronisation GitHub

            La progression est enregistrée dans un dépôt privé, et les cartes que tu modifies dans le dépôt du site. Le jeton reste sur cet appareil.

            Import de cours (Gemini)

            Pour générer des cartes à partir d'un PDF, crée une clé API gratuite sur Google AI Studio (connexion avec un compte Google, puis « Create API key »).

            Ouvrir Google AI Studio

            La clé reste sur cet appareil. Avec l'offre gratuite, Google peut utiliser les documents envoyés pour améliorer ses modèles : n'envoie que des cours, rien de personnel.

            Sauvegarde manuelle

            Emploi du temps (Mon Bureau Numérique)

            L'appli récupère ton emploi du temps deux fois par jour grâce à un jeton de connexion. Ton mot de passe n'est enregistré nulle part.

            1. Sur ton ordinateur, télécharge scolengo-token depuis sa page de téléchargement (fichier .exe pour Windows).
            2. Ouvre-le, cherche ton lycée puis connecte-toi comme sur Mon Bureau Numérique.
            3. Copie tout le texte affiché à la fin (il commence par « { ») et colle-le ci-dessous.

            Ce jeton donne accès à ton compte ENT : ne le partage avec personne. Il est rangé dans ton dépôt privé.

            Paquets Anki

            Importer un paquet (.apkg)

            Les cartes, les textes à trous et les images sont repris ; chaque sous-paquet devient un chapitre de la matière choisie.

            Exporter vers Anki

            Coche les chapitres à exporter : Anki ouvre le fichier avec un sous-paquet par matière et par chapitre.
